# Description
A small World of Warcraft Classic add-on that lets [Outfitter](https://www.curseforge.com/wow/addons/outfitter-retrofit) outfits swap your ammo too. Outfitter doesn't save the ammo slot, so swapping between a bow and a gun outfit leaves the wrong ammo equipped.

- Right-click an outfit in Outfitter and use the Ammo submenu to link the ammo you have equipped to it
- Wearing the outfit equips its linked ammo, in combat it waits until combat ends
- Renaming an outfit keeps its ammo, deleting it removes the link
- Links are saved per character
